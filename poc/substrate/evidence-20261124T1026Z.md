## B. 非 root bind :443（runc/内核侧），以及修法

```
# Deployment 里已经有 NET_BIND_SERVICE
$ kubectl -n ate-system get pod <ate-api-server> -o jsonpath='{.spec.containers[0].securityContext}'
{"allowPrivilegeEscalation":false,"capabilities":{"add":["NET_BIND_SERVICE"],"drop":["ALL"]},"runAsNonRoot":true}

# 但进程实际没拿到 effective/permitted caps
CapPrm: 0000000000000000
CapEff: 0000000000000000
CapBnd: 0000000000000400        # = CAP_NET_BIND_SERVICE 只在 bounding
nc: bind: Permission denied     # busybox 复现

# 新 netns 不继承节点 sysctl
$ cat /proc/sys/net/ipv4/ip_unprivileged_port_start      # 节点=80（我设过），Pod 内=1024

# 修法：Pod 级 sysctl，立即生效
spec.securityContext.sysctls: [{name: net.ipv4.ip_unprivileged_port_start, value: "80"}]
→ 80 / BIND-OK
```

对应报错原文（没修之前）：

```
{"level":"ERROR","msg":"Failed to start listener","err":"listen tcp :443: bind: permission denied"}
{"level":"ERROR","msg":"Error while executing","err":"while opening atunnel listener: listen tcp :443: bind: permission denied"}
```
